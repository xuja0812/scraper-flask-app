# Google Review Analyzer

## Overview
This full-stack web application allows a user to log in and analyze the Google reviews of a business of their choosing. The frontend is built using React and Tailwind, and the backend uses Flask and MySQL. Sentiment analysis of all of the reviews are done using a custom neural network created using PyTorch and a TF-IDF vectorizer.

## Tech Stack
### Frontend: 
React, Tailwind CSS, Vite

### Backend: 
Flask, Selenium, BeautifulSoup, MySQL, PyTorch

## Features
_Google Review Scraper_: Collects reviews automatically using Selenium-based web automation.

_Custom Sentiment Classifier_: Built and trained from scratch using PyTorch to classify reviews as positive, negative, or neutral.

_User Accounts_: Registration, login, and persistent analysis history with MySQL.

_Data Visualization_: Sentiment distribution displayed with interactive bar and pie charts.

_Frontend with React_: Clean, responsive UI built with Tailwind CSS and Vite.

_Backend with Flask_: Secure API endpoints to handle authentication, review scraping, and model inference.
